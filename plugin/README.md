# Ibmec Conecta

No Gemini normal, abra um chat e arraste a pasta plugin. Se a interface
aceitar apenas arquivos, selecione os Markdown da pasta e anexe-os juntos.
Envie **Instale esse plugin** e depois faça sua pergunta.

Comece pelo [guia de instalação](INSTALACAO.md). O [calendário público](CALENDARIO.md)
contém a base de demonstração de 2026.1 e 2026.2 para consultas nesta conversa.
A integração opcional com servidor está em [CONEXAO.md](CONEXAO.md).
