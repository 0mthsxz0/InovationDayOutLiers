# Calendário acadêmico público

Consulte o calendário atualizado, sem login, pela ferramenta consultar_calendario ou pela API pública. Escolha o semestre 2026.1 ou 2026.2.

[Consultar o calendário de 2026.2](https://ibmec-conecta-calendario.onrender.com/api/calendario?semestre=2026.2)

Se o chat não puder acessar a API, envie o link ao usuário e informe que não foi possível verificar as datas. Use somente os dados retornados pelo servidor.
